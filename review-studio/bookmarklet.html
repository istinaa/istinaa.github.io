CF Import Bookmarklet

CF 导入书签脚本

先启动本地 Review Studio，再登录 Codeforces，打开你要写题解的 group contest 页面，点击这个书签脚本即可导入比赛标题和题目列表。

  1. 在仓库目录运行 node scripts/review-studio-server.js，或运行 npm run review:studio。
  2. 访问 http://127.0.0.1:4126/bookmarklet.html。
  3. 把下面这个蓝色按钮拖到浏览器收藏夹栏。
  4. 在 Codeforces 比赛页点击它。
  5. Review Studio 会在 http://127.0.0.1:4126/ 自动打开并导入题号和题目名。

如果拖拽收藏按钮不方便，也可以复制下面整段脚本，手动新建一个收藏，把网址粘进去。

导入到 Review Studio

不要从本地 file:// 页面使用这个功能。Codeforces 页面通常不允许直接打开本地文件，这也是你刚才报错的原因。

要求当前页面是 Codeforces 比赛题目列表页，例如 `/contest/...` 或 `/group/.../contest/...`。
