⌈26春训⌋ 第一场题解

B Blackboard Game

题目大意：

起始给定 3n 个数。先手每次选一个，后手每次选一个删一个。 n 轮后游戏结束，如果此时两人选取数的总和不等则先手胜利。问先手能否保证获胜。

知识点： 博弈论。

显然对于先手来说，一个很好的策略是总是选取当前剩下数中最大的一个。

在这种策略下，后手唯一获胜的局面是：每种数字出现的次数都是三的倍数。大胆猜测就成功做出了这道题。

C Candy Rush

题目大意：

给定长度为 n 的数组，包含 k 种元素。找出一个最长的连续子区间，使得 k 种元素在其中都出现，且出现次数都相同。其中 n,k≤4×105 。

知识点： 前缀和，哈希。

对 k 种元素分别计数，做前缀和 sumk(1⋯n) 。如果区间 [L,R] 满足题目条件，则可以得到：对于所有的 i∈{1⋯k} ， sumi(R)−sumi(L−1) 都相等。

任取 i,j∈{1⋯k} ，有 sumi(R)−sumi(L−1)=sumj(R)−sumj(L−1) 。

移项可得 sumi(R)−sumj(R)=sumi(L−1)−sumj(L−1) 。

进一步可以得到任取 i∈{1⋯k} ，都有 sumi(R)−sum1(R)=sumi(L−1)−sum1(L−1) 。

于是我们对于所有 x∈{1⋯n} ，计算出一个 k−1 维特征向量 [sum2(x)−sum1(x)sum3(x)−sum1(x)⋯⋯sumk(x)−sum1(x)] ，记作 vec(x) 。

如果存在 0≤i<j≤n 使得 vec(i)=vec(j) ，可知 [i+1,j] 是满足题意的区间。

比较特征向量我们需要用到哈希。定义 vec(x) 的哈希值如下：

hash(vec(x))=∑i=1k−1vec(x)iBi−1mod p

接下来看特征向量是如何计算的。和 vec(x) 相比， vec(x+1) 可能的差异分两种：

  • 若 ax+1 是 1 ， vec(x+1) 在各维上都减了 1 。体现在哈希值上就是改变了一个定值 ∑i=1k−1Bi−1mod p ，可以提前预处理。
  • 若 ax+1 不是 1 ， vec(x+1) 在对应维上加了 1 。体现在哈希值上就是加上了一个 B 的相应的幂次。可以 O(1) 解决。

实现层面上，我们线性扫一遍，扫描过程中计算哈希值。同时我们将出现过的哈希值扔进 map<int, int> 进行维护。找出相距最远的一对同哈希值下标即可。需要注意的是，本题的哈希冲突概率不低，最好使用双哈希进行保险。

D Deciphering WordWhiz

题目大意：

给定一个大小为 N 的字典。每个单词由五个互不相同的字母构成。同时给定一个保证在字典中的目标单词。

每次查询给定一个长度为 5 的反馈串（由 * ! X 组成，分别代表字符位置都正确、存在该字符但位置不对以及目标单词中不含此字符）问：字典中有多少单词与目标单词比对时，恰好产生该反馈串。

知识点： 读题面。

由于本题数据规模太小，直接 O(5NG) 级别的暴力扫描就可以通过。

F Forward and Backward

题目大意：

给定 N ，求有哪些处于 [2,N] 中的 b 使得 N 的 b 进制表示是一个回文串。其中 N≤1012 .

知识点： 分治。

b 越大， N 的 b 进制表示就越短。如当 b 达到 N 级别时，表示串最多只有两位。

这种情形下有 xb+x=N 。于是我们可以通过枚举式中的 x 检查有多少超过 N 的 b 。

至于小于 N 的部分，我们可以枚举 b ，然后直接对 N 进行进制转换然后检查是否是回文串。

总时间复杂度 O(N+Nlog⁡N) 。实现时注意常数就可以通过本题。

I Inversions

题目大意：

给定一个字符串 S 和一个正整数 n ，求首尾相接的 n 个 S 组成的新串中逆序对的数量。其中 |S|≤105,n≤1012 。

知识点： 逆序对。

随意从 S 中取能够使 Si<Sj 的下标 i 和 j ，计算其对最终答案的贡献。

由于 Si<Sj ，那么一定有 Si+p|S|<Sj+q|S| 。（其中 p 和 q 是小于 n 的自然数） 那么问题转化为求满足 i+p|S|<j+q|S| 的有序对 (p,q) 的对数。

分两种情况讨论。

第一种情况， i>j 。那么想要满足要求，需满足 p<q 。通过简单的组合数计算可知，答案是 n(n−1)/2 。

第二种情况， i<j 。需满足的要求是 p≤q 。答案是 n(n+1)/2 。

接下来我们统计这两种情况分别出现的次数。第一种情况其实就是针对原串中每个字符，求出它左侧比它大的字母的个数，然后求和即可。第二种情况则是改为求右侧。

这其实就是求逆序对数了。由于字符串值域很小，可以直接用前缀和等手段统计。如果值域大的话也可以先离散化，然后在权值线段树上求解。时间复杂度 O(26|S|) .

M Meeting Point

题目大意：

给定一个 n 个点 m 条边的带权无向连通图，以及起点 P 和中点 G 。

寻找所有的终点 X ，满足：从 P 到 X 的 **所有 **最短路径都必须经过 G ，且 P 到 G 的最短距离等于 G 到 X 的最短距离。

其中 n,m≤105 。

知识点： 最短路。

以 G 为起点跑一遍最短路。所有满足 G⇒X 与 G⇒P 距离相等的点 X 构成点集 S 。答案一定是 S 的子集。

能进入答案的点 X 必须满足： P⇒X 的最短路径经过 G 。也就是说，如果从图上删去 G ，以 P 为起点跑最短路， P⇒X 的距离会变大。依据这一点删去部分点后得到的点集就是最终答案了。时间复杂度同最短路算法。
